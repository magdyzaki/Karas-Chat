# خطوات التشغيل الصحيحة لـ chat-app-new

---

## مهم جداً: الترتيب

1. **شغّل الباكند أولاً** ← واترك النافذة مفتوحة
2. **بعدها شغّل الفرونتند**

لو عملت العكس، هتظهر أخطاء `ECONNREFUSED` و `ws proxy error`.

---

## الخطوة 1: تشغيل الباكند

### افتح Command Prompt أو PowerShell واكتب:

```
cd D:\programs\Smart_CRM_Final_Arabic\chat-app-new\backend
npm start
```

### انتظر حتى تظهر الرسالة:
```
Chat backend on 5002
```

### اترك هذه النافذة مفتوحة — لا تغلقها

---

## الخطوة 2: تشغيل الفرونتند

### افتح نافذة جديدة (Command Prompt أو PowerShell) واكتب:

```
cd D:\programs\Smart_CRM_Final_Arabic\chat-app-new\frontend
npm run dev
```

### افتح الرابط الذي يظهر (مثل https://localhost:5173)

---

## أو استخدم الملف الجاهز

في مجلد `chat-app-new` فيه ملف **تشغيل-الباكند.bat**
- اضغط عليه مرتين لتشغيل الباكند
- اترك النافذة مفتوحة
- بعدها شغّل الفرونتند من نافذة أخرى

---

## لو ظهر خطأ EPERM عند تشغيل الباكند

- تأكد أن no برنامج تاني فاتح ملف `db.json` (مثلاً من Cursor أو Notepad)
- أوقف أي instance قديم من الباكند (من Task Manager لو لزم)
- جرب تشغيل الـ batch file كـ Administrator (كليك يمين → Run as administrator)
