# تشخيص مشكلة "Failed to fetch"

## اختبارات يجب أن يجريها صديقك (بالترتيب)

### 1. اختبار Vercel API البسيط
اطلب من صديقك فتح هذا الرابط في المتصفح:

```
https://karas-chat.vercel.app/api/ping
```

**المتوقع:** `{"ok":true,"t":...,"msg":"Vercel API يعمل"}`

- ✅ يعمل → الـ API منشور والاتصال بـ Vercel سليم
- ❌ 404 أو خطأ → الـ API غير منشور أو الإعداد خاطئ

---

### 2. اختبار consume-invite مباشرة (بدون استهلاك الرابط)
اطلب منه فتح (لا تستخدم رابط دعوة حقيقي — استخدم token وهمي):

```
https://karas-chat.vercel.app/api/consume-invite?token=test123
```

**المتوقع:** `{"ok":false,"error":"رابط غير صالح"}` أو `{"ok":false,"error":"الرابط مُستهلَك مسبقاً"}`

- ✅ يصل للصفحة ويُظهر JSON → الـ endpoint يعمل
- ❌ Failed to fetch أو 404 → مشكلة في الطلب أو الـ endpoint

---

### 3. اختبار Render مباشرة
```
https://karas-chat-backend.onrender.com/api/health
```

**المتوقع:** `{"ok":true}`

- ✅ يعمل → الاتصال بـ Render سليم
- ❌ لا يعمل → شبكة صديقك قد تحجب Render

---

## ملخص التشخيص

| الاختبار | النتيجة | الدلالة |
|---------|---------|---------|
| /api/ping | ✅ | Vercel API يعمل |
| /api/ping | ❌ | مشكلة في نشر الـ API أو Vercel |
| /api/consume-invite?token=test | ✅ | الـ proxy يعمل |
| /api/consume-invite?token=test | ❌ | مشكلة في consume-invite أو الطلب |
| Render /api/health | ✅ | الاتصال بـ Render سليم |
| Render /api/health | ❌ | حجب أو مشكلة شبكة |

---

## التعديلات المُضافة

1. **GET بدل POST (أول محاولة):** طلب GET أبسط وقد ينجح لو الشبكة تحجب POST
2. **Endpoint للتشخيص:** `/api/ping` لا يستدعي أي خدمة خارجية
3. **تعديل vercel.json:** تأكيد أن مسارات `/api/*` لا تُعاد كتابتها إلى `index.html`
