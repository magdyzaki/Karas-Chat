# ربط التطبيق على الموبايل بالباكند

التطبيق يحتاج يتصل بـ **الباكند** علشان التسجيل والدردشة تشتغل.

---

## 1) شغّل الباكند واعرف الرابط

### لو الباكند محلي (على جهازك):

```bash
cd D:\programs\Smart_CRM_Final_Arabic\chat-app-new\backend
npm start
```

ثم شغّل **ngrok** علشان الموبايل يقدر يوصل للباكند:

```bash
ngrok http 5002
```

انسخ الرابط اللي يطلع (مثل: `https://xxxx.ngrok-free.app`)

---

## 2) ضبط الرابط في الواجهة

افتح ملف:
```
chat-app-new\frontend\.env
```

عدّل السطر:
```
VITE_API_URL=https://رابط-ngrok-هنا
```

**مهم:** بدون `/` في الآخر. مثال: `https://abc123.ngrok-free.app`

---

## 3) إعادة بناء التطبيق

```bash
cd D:\programs\Smart_CRM_Final_Arabic\chat-app-new\frontend
npm run build
```

ثم:

```bash
cd D:\programs\Smart_CRM_Final_Arabic\chat-app-new\google-play
npx cap sync android
```

ثم شغّل:
```
بناء-release.bat
```

---

## 4) تثبيت التطبيق الجديد

انسخ ملف `app-release.apk` للموبايل وثبّته (أو امسح التطبيق القديم وثبّت الجديد).

---

## ملاحظة

- **الباكند لازم يكون شغّال** طول ما بتستخدم التطبيق
- لو أطفيت ngrok أو أعدت تشغيله، الرابط يتغير ← لازم تعيد الخطوات 2 و 3 و 4
- لو حابب التطبيق يشتغل بدون جهازك: انشر الباكند على سيرفر (Koyeb، Railway، إلخ) وضعه في `VITE_API_URL` بدل ngrok
