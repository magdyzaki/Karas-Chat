# Karas شات — نسخة WhatsApp كاملة

تطبيق دردشة كامل شبيه بـ WhatsApp: رسائل، وسائط، مكالمات، حالة القراءة، قصص، بث، ومزيد.

---

## الميزات

| الميزة | الوصف |
|--------|-------|
| **التسجيل والدخول** | بريد أو رقم موبايل، تحقق برمز، أرقام موثوقة |
| **المحادثات** | فردية ومجموعات |
| **الرسائل** | نص، صورة، فيديو، صوت، موقع، استطلاع، رد على رسالة |
| **حالة القراءة** | ✓ تم الإرسال، ✓✓ تم الاستلام، ✓✓ أزرق تمت القراءة |
| **المكالمات** | صوتية وفيديو (WebRTC) |
| **القصص** | تُنشر لمدة 24 ساعة |
| **قوائم البث** | إرسال رسالة واحدة لعدة جهات |
| **الإعدادات** | كتم، أرشفة، رسائل مؤقتة |
| **PWA** | التثبيت، التنبيهات |
| **دعوات** | روابط دعوة للآيفون والأندرويد |

---

## التشغيل

### 1. تشغيل الباك اند والفرونت معاً (مُفضّل)

```powershell
cd D:\programs\Smart_CRM_Final_Arabic\whatsapp-clone
npm install
npm run dev
```

### 2. أو تشغيل كل واحد على حدة

**الباك اند (شغّله أولاً):**
```powershell
cd whatsapp-clone\backend
npm install
npm run dev
```

**الفرونت اند (في طرفية ثانية):**
```powershell
cd whatsapp-clone\frontend
npm install
npm run dev
```

### 3. فتح التطبيق

- **HTTP:** http://localhost:5173  
- **HTTPS (للموبايل/الكاميرا):** https://localhost:5173 أو https://192.168.x.x:5173

---

## إعدادات الباك اند (.env)

```env
PORT=5002
JWT_SECRET=غيّر-هذا-في-الإنتاج
SKIP_VERIFICATION=true
TRUSTED_PHONES=01229084204,201229084204
```

- **TRUSTED_PHONES:** أرقام تُفعّل فوراً بدون رمز تحقق (مثال: 01X و 20X)
- **SKIP_VERIFICATION=true:** تجاوز التحقق للجميع (للتطوير فقط)
